# Static Portfolio Website

## Project Overview
This project is a simple, responsive personal portfolio website developed using HTML, CSS, and JavaScript. It introduces the developer, displays skills and projects, and provides contact information.

## Objectives
- Create a static website using HTML.
- Design the layout using CSS Flexbox.
- Implement a JavaScript welcome splash screen.
- Make the website responsive for desktop and mobile devices.
- Publish the project using GitHub.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Project Structure

```text
static-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Features
1. Welcome splash screen with an Explore Portfolio button.
2. Navigation links to Home, About, Projects, and Contact.
3. Personal introduction and skills section.
4. Project cards.
5. Email contact link.
6. Responsive layout using CSS Flexbox and a media query.
7. Automatic display of the current year in the footer.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension or a web browser.
4. Click Explore Portfolio to enter the website.
5. Test the navigation links and project sections.

## How to Deploy
The website can be published using GitHub Pages. Open the repository Settings, select Pages, choose Deploy from a branch, select `main` and `/(root)`, and save.

## Testing
- Verify that the welcome screen appears on page load.
- Verify that the welcome screen closes when the button is clicked.
- Verify that the screen closes automatically after five seconds.
- Test navigation links and the email link.
- Check the layout at desktop and mobile screen widths.
- Check the browser console for JavaScript errors.
